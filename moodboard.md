# Pohjanpiha Festival – Moodboard

## 1. Visual Identity

The website design is inspired by the Pohjanpiha Festival visual identity. It uses navy blue, white and coral red to create a clear and bold appearance.

## 2. Colour Palette

* Navy blue: #1b2a4a
* Light background: #f4f6fb
* Coral red: #b8321b
* White: #ffffff

The colours create a strong contrast and help visitors read the website.

## 3. Typography

Arial is used because it is simple, clear and easy to read. Bold headings make important information stand out.

## 4. Layout

The website has four pages: Home, About, Programme and Contact. The navigation is consistent across all pages.

## 5. Responsive Design

The website adapts to mobile screens and desktop screens. The layout is designed to work at 320px without horizontal scrolling.

## 6. Accessibility

The website includes keyboard focus indicators, readable text, colour contrast and a dark mode that follows the visitor's system settings.

## 7. Design Goal

The goal is to create a simple, fast and accessible festival website where visitors can easily find programme information and contact the organisers.
