# Software Engineering Course Project, Fall 2026
**Author:** Prothoma Linda
## Background
Lasers and Feelings is a quick-play roleplaying game. It is based on a premise where the crew of an interstellar scout ship named Raptor must explore uncharted space, handle alien encounters, and protect Consortium worlds while their captain recovers in a medical pod.
## Introduction
A Game Master (GM) leading a Lasers and Feelings session needs software to help players and themselves run the game. The core functionality requires handling dice rolls, with additional support for managing character details, ship status, adventure generation, and overall session tracking.
## Dictionary
* **GM (Game Master):** The person managing and running a Lasers and Feelings session.
* **Raptor:** The interstellar scout ship operated by the player character crew.
* **Lasers:** The character stat used for science, tech, precision, and engine operations.
* **Feelings:** The character stat used for intuition, diplomacy, passion, and personal connections.
## Requirements
* **As a player**, I want to roll a pool of six-sided dice against my chosen stat so that I can determine if my character succeeds in an action.
* **As a GM**, I want to generate random adventure elements (threat, location, and twist) so that I can quickly set up a game session.
* **As a player**, I want to create and view a digital character sheet so that I can track my character's style, role, and stat number during play.
* **As a GM**, I want to track the current health and status of the ship so that the group knows what condition their vessel is in during encounters.
